# Скрипты анализа к статье

Воспроизводят раздел «Пример применения» статьи (эксперимент со стимулами в сетке 2×2). **Данные участников в репозиторий не входят**: скрипты принимают пути к вашим файлам.

Порядок:

1. `extract_cells.py` — границы четырёх фотографий в каждом составном стимуле (по PNG стимулов).
2. Карты салиентности: инструмент (режим «составной стимул») → `saliency_cells.json` (поля `file, method, cell, share, …`; ячейки `R1C1…R2C2`) и `pics_saliency.json` для отдельных фотографий.
3. `gaze_cells.py` — доля времени взгляда по ячейкам из экспорта «Нейробюро» (`fixations_saccades.csv`).
4. `salience_vs_gaze.py` — положение в сетке, баланс подбора по сравнению со случайным (перестановки), связь салиентности и взгляда по группам стимулов.
5. `condition_effects.py` — эффект эмоционального условия до и после поправки на салиентность (смешанная модель + МНК с бутстрепом по изображениям); нужен файл `cell_conditions.csv` (`stim, cell, cond, kind`).

Зависимости: `pip install numpy pandas scipy pillow statsmodels`.

Разметка условий (`cell_conditions.csv`) в статье — экспертная оценка автора анализа и требует независимого подтверждения, поэтому в репозиторий не включена.
