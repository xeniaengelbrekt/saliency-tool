# Saliency — браузерный модуль оценки визуальной салиентности стимулов

Программный инструмент для количественного контроля визуальной заметности
стимулов в исследованиях зрительного восприятия и внимания. Работает
полностью в браузере, без установки и без серверной обработки данных.

**Живая версия:** https://xeniaengelbrekt.github.io/saliency-tool/

---

## Что умеет

**Основной модуль (`salience.html`):**

- Анализ одного стимула — тепловая карта, семь числовых метрик с интерактивными пояснениями, гистограмма распределения значений салиентности
- Сравнение нескольких стимулов или составного стимула (2×1 / 1×2 / 2×2) — матрица корреляций Пирсона между картами, попарные различия метрик; в составном стимуле регионы сравниваются на общей шкале (доля салиентности каждого региона)
- Автоматический подбор сбалансированных наборов из нескольких категорий изображений (2–4 группы) — по одной или нескольким метрикам, несколько непересекающихся наборов, проверка баланса однофакторным ANOVA
- 4 алгоритма оценки: Frequency-Tuned Saliency (Achanta et al., 2009), Difference of Gaussians, Local Color Contrast, Spectral Residual (Hou & Zhang, 2007)
- Экспорт в CSV, PNG, ZIP

**Айтрекинг-модуль (`eyetracking.html`):**

- Сравнение тепловых карт айтрекинга с предсказаниями моделей салиентности
- 6 стандартных метрик соответствия (по MIT/Tuebingen Saliency Benchmark): CC, NSS, AUC-Judd, shuffled AUC, SIM, KL-divergence
- Ориентиры: центральный baseline и верхний предел по согласованности участников (split-half)
- Метрики по участникам с 95 % доверительными интервалами; пакетный расчёт по всем стимулам CSV
- Учёт положения стимула на экране (по центру / растянут / вручную), координаты в долях 0–1
- Поддержка CSV-выгрузок из стандартных пакетов (Tobii Pro Lab, BeGaze SMI, GazePoint, EyeLink Data Viewer, OGAMA): распознавание колонок по названию, ручной выбор колонок, удаление повторов фиксаций в покадровых выгрузках

## Быстрый старт

**Онлайн:** открой ссылку GitHub Pages (см. выше) — всё работает в браузере.

**Локально:** скачай `salience.html` или `eyetracking.html` — двойной клик, работает в любом современном браузере.

Никакой установки, никаких зависимостей, никаких аккаунтов не требуется.

## Разработка

Модульный исходный код в `js/` подключается через ES-модули. Для локального
запуска dev-версии нужен HTTP-сервер (двойной клик по `index.html` не сработает
из-за ограничений CORS для модулей).

**Windows:** двойной клик по `start.bat` — запустит локальный сервер на
http://localhost:8765 (требует Python 3).

**Сборка single-file бандлов** после правки исходников:

```
py build.py
```

Скрипт склеивает `js/` и `css/style.css` в два самодостаточных HTML-файла:
`salience.html` и `eyetracking.html`. Требует Python 3, без сторонних библиотек.

**Автотесты** (45 проверок вычислительного ядра: точные значения, независимые реализации
алгоритмов, свойства симметрии, разбор CSV, регрессионные эталоны):

- в браузере: `start.bat` → http://localhost:8765/tests/
- в Node ≥ 18: `node tests/run-node.js`

На GitHub тесты и актуальность собранных файлов проверяются автоматически при каждой загрузке.
