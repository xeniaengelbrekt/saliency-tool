# Скрипты анализа к статье

Воспроизводят раздел «Пример применения» статьи (эксперимент со стимулами в сетке 2×2). **Данные участников в репозиторий не входят**: скрипты принимают пути к вашим файлам.

Порядок:

1. `extract_cells.py` — границы четырёх фотографий в каждом составном стимуле (по PNG стимулов). Если области интереса уже размечены в «Нейробюро», вместо этого запустите `aoi_table.py` — таблица «область → положение, условие, категория», `cells_aoi.csv` и `cell_conditions.csv` из `aoi_geometry.csv`.
2. Карты салиентности: инструмент (режим «составной стимул») → `saliency_cells.json` (поля `file, method, cell, share, …`; ячейки `R1C1…R2C2`) и `pics_saliency.json` для отдельных фотографий.
3. `gaze_cells.py` — доля времени взгляда по ячейкам из экспорта «Нейробюро» (`fixations_saccades.csv`).
4. `salience_vs_gaze.py` — положение в сетке, баланс подбора по сравнению со случайным (перестановки), связь салиентности и взгляда по группам стимулов.
5. `condition_balance.py` — условия по позициям (χ²) и средняя салиентность по условиям с перестановочным тестом.
6. `condition_effects.py` — эффект эмоционального условия до и после поправки на салиентность (смешанная модель + МНК с бутстрепом по изображениям); нужен файл `cell_conditions.csv` (`stim, cell, cond, kind`).

Зависимости: `pip install numpy pandas scipy pillow statsmodels`.

Разметка условий (`cell_conditions.csv`) задаётся порядком областей интереса, нарисованных авторами эксперимента; в репозиторий её не включаем.
